# 금융통계 기말 프로젝트 · 추가 데이터 추출

학교 서버의 기존 중복 제거 패널에서 실제 거래일·종목마다 선택된 아카이브 파일을 읽는다. 원본 HTML은 학교 서버에 두고, 기존 가격·업종 패널에 거래량·시가총액·PBR을 덧붙인다. 종목 페이지의 연간·분기 기업실적분석 표는 추정치와 확정치를 구분하며, 내용이 바뀔 때 버전을 저장한다.

학교 서버 작업 경로는 `~/bank-final/enriched`이다.

- `full/daily/YYYY-MM-DD.csv.gz`에는 종가, 전일가, 업종 등 기존 열과 거래량(주), 시가총액(원), PBR(배), 추출 상태가 있다.
- `full/financials.sqlite`의 `finance` 테이블에는 종목별 실적 표 변경 버전이 있다. 이미 관측한 값과 동일한 표는 반복 저장하지 않는다.
- `full/earnings_transitions.csv`에는 영업이익 추정치를 먼저 관측하고 이후 확정치가 처음 나타난 연간·분기 사례가 있다. 날짜는 보관본에서 확인한 관측 시점이다. 이전 관측 열은 직전 변경 버전의 날짜를 뜻한다. 공시 시각이나 마지막으로 동일한 추정치가 반복된 거래일은 별도 확인이 필요하다.
- `full/coverage.csv`에는 완료 후 날짜별 열 확보 수와 파싱 상태가 기록된다. 누락 필드는 빈 값으로 유지한다.

진행 확인

```bash
tail -n 5 ~/bank-final/enriched/full.log
find ~/bank-final/enriched/full/daily -maxdepth 1 -name '*.csv.gz' | wc -l
```

완료 표시는 로그의 `COMPLETE`다. 중단됐다면 기존 실행이 종료된 상태에서 같은 코드·입력·출력 경로로 다시 실행해 완료 거래일부터 이어갈 수 있다.
